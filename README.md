# Loop Practice

An Android music practice player.

- Plays MP3, WAV, FLAC, M4A/AAC, OGG and Opus files, plus the audio track of video files.
- Changes speed from 25% to 200% while keeping the pitch.
- Shifts pitch by ±12 semitones, separately from speed.
- Multiple loops (A, B, C, …): tap a letter to jump there and loop it at once.
- Loop points can be set at the current position ("Now") or nudged in 0.01, 0.1 or 1 s steps.
- Speed trainer: raises the speed a little every few repeats.
- Loops are saved per file.

## Install

On the phone, open
**https://github.com/boykohub/LoopPractice/releases/latest/download/LoopPractice.apk**,
then open the downloaded file. Android asks you to allow installs from your browser the first time.

Every push to `main` is built by GitHub Actions and published as a new release.
